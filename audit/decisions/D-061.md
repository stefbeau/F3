# D-061 — AI-Direct Data Campaign

**Date:** 2026-10-28
**Status:** open
**Editor:** Stéphane Beau

## Motivation
F3's differentiator is modelling the AI-economy-planet nexus. D-060 covered
planetary systems broadly. D-061 targets datasets that measure AI itself —
compute, adoption, labour impact, investment, governance, benchmarks, and
AI's direct resource footprint — to feed the S3 AI-economy module and the
proposed L8–L_RISK link codes in docs/architecture.md.

## Tasks for Claude Code
For each source:
1. Fetch the URL (follow redirects)
2. Confirm: title, licence, access method (open/registration/paywall),
   current version or year of latest data, what variables/metrics it covers
3. Register in audit/data/sources-register.json with status:
   - "partial" if page loads and data is accessible
   - "blocked" if paywall, 403, or registration wall
   - Add supports_proposed field with relevant link codes from
     docs/architecture.md (L8, L9, L_BIO, L_FIN, L_SOC, L_RISK, etc.)
4. Add blocked sources to needs-user.json
