# Model versus reality: readings fixed before the data were compared (D-057)

Written 2026-10-22, **before any model series was set against any observed series**. Nothing below is an acceptance criterion of the plan; these are descriptive readings for a public chart, set by Claude (Provisional, D-057) and open to change by the editor. If a reading is changed after the numbers are seen, the change is recorded as post-hoc.

No parameter, equation or run of any model is changed or tuned. The comparison uses the series already in `site/data/explorer.json` (World3 grid, recorded FaIR) plus a FaIR hindcast with the same published 841-member configuration (D-021, D-030), run to 2026 so that calendar years 1850 to 2025 exist.

## Series and conventions
| Panel | Model series | Observed series | Convention |
|---|---|---|---|
| Population | World3 `pop` (p1+p2+p3+p4) of the selected run | UN WPP 2024, World, medium variant, total population, 1 July, thousands | World3 sits at 1 January; the model value for year Y is the mean of the model values at Y and Y+1 (mid-year). WPP 2024 estimates end in 2023; 2024 and later are the UN medium projection and are drawn hollow and **never used in the gap test**. |
| Industrial output and GDP | World3 `io` of the selected run | World Bank WDI `NY.GDP.MKTP.KD`, World, constant 2015 US$ | Both indexed to 1990 = 1, nothing else. World3 `io` is in model dollars (World3's own constant dollars); the two are **not the same quantity** (industry only against all GDP; different dollars). Calendar-year model value = mean of Y and Y+1. |
| Temperature | FaIR 841-member hindcast, calendar-year anomaly (mean of the time bounds at the start and end of the year), K above 1850-1900 | HadCRUT5 (version recorded in `audit/data/sources-history.json`) annual best estimate, re-based to the mean of the annual best estimates 1850-1900, as in `tests/fair_checks.py`; GISTEMP only as a cross-check | Same method as A2.1 (`audit/m2-fair-report.md`). |

## Last common year and the test sentence (fixed now)
* Population: last common **estimate** year = 2023. Gap = (model - observed) / observed, in percent. Reading: **within** if |gap| <= 5%, otherwise **outside**. (UN WPP's own uncertainty is about 1% for the world total; 5% is a plain-language band, not a tolerance of the plan.)
* Industrial output and GDP index: last common year = 2025 (or the last year both exist). Gap = (model index - observed index) / observed index, in percent. Reading: **within** if |gap| <= 25%, otherwise **outside**. The wide band is because the quantities differ; the sentence says so every time.
* Temperature: last common year = 2025. Gap = FaIR ensemble mean minus HadCRUT5 best estimate, in K. Reading: **inside** if the FaIR mean lies in HadCRUT5's 95% interval for that year (the form of A2.1), otherwise **outside**; the sentence also says whether HadCRUT5's best estimate lies in the FaIR 5th to 95th percentile band.
* Every sentence is generated by the page script from the data (`historyGap*` functions); tests in Node run it on the committed data and on synthetic data, so a hard-coded sentence would fail.

## Status statements that must appear where they apply
* Population panel: S1 inside the full World3 run differs from S1 alone with recorded inputs by up to 0.93% (A3.4(b) FAILED, 0.25% required); World3 with changed levers has not been compared with WorldDynamics.jl.
* Temperature panel: A2.1 FAILED (FaIR 2015-2024 mean 0.037 K below HadCRUT5's interval); the ensemble was constrained to temperatures up to 2022, so 2023 onward is out of sample, and 2015-2022 is in sample (not an independent test).
* Every panel: **a comparison with history is not a validation.** World3 is a 1970s-era structural model (2004 parameter set here); it was not fitted to these series and is not expected to match them. The chart exists to show the distance, not to close it.

## What a reader must not be told
* That the model "tracks", "reproduces" or "is validated by" observed history, whatever the gap.
* That the World3 industrial index and observed GDP are one quantity.
