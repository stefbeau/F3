# L7 — History for calibrating the coupled model (draft, D-058)

**Status of this page:** data inventory for a backtest, written before any code or test run. No result is reported. Provisional (delegated). Link numbering as in L3.md. L7 is not a causal link but the data end of Phase 3 (calibrate): the observed series each sector output must be compared with.

## What must connect
Model outputs for 1970-2025 (coupled run) to observed series for population, output, labour, energy, emissions, concentration, warming, food and minerals, using the time convention of D-022 (annual values of flows are totals for the calendar year; stocks are 1 January values).

## Functional forms in the literature
Backtest practice, not a model form: error statistics against observed series with an explicit tolerance and a stated horizon (the World3 and Earth4All literature compares shapes; Meadows et al. 1972, Randers et al. 2024) [from memory, unverified], hindcast with held-out windows, Monte Carlo over the FaIR ensemble plus S3 parameter uncertainty. The existing precedent is `docs/history-comparison.md` and the warming map.

## Pass/fail test (written without results)
1. For each series in the table with at least 30 annual points, fix the metric (relative error, median and 95th percentile, as in the Earth4All audit) and the tolerance before running.
2. The backtest is run once on frozen parameters; failures are recorded, never adjusted (CLAUDE.md rule 2).
3. Series with only one observation (minerals 2024) are used as level checks only and reported as such.
4. Each comparison states whether the observed series is itself a model product (WPP projections after 2024, Ember estimates, CEDS scaled to energy statistics).
