## D-050 item 4: can each sign test fail on the real module? (`audit/t0/s7_mutation_check.py`)
The module's equations were broken one at a time (each text replacement matched exactly once; each test run in a fresh process with a fresh bytecode cache; the module restored byte for byte afterwards, verified). **Pre-registered tests caught 9 of 13 mutations; 4 were MISSED.**

| Mutation | Test | Result |
|---|---|---|
| R2: labour-share pressure never feeds inequality (**the pre-registered R2 mutation**) | `test_r2_automation...` | **CAUGHT** |
| R2: inequality does not raise tension | `test_r2_automation...` | **MISSED** |
| R2: tension does not lower well-being | `test_r2_automation...` | **MISSED** |
| B5: policy response never starts (**the pre-registered B5 mutation, kP = 0**) | `test_b5_policy...` | **CAUGHT** |
| B5: no delay (tau_P tiny) | `test_b5_policy...` | **MISSED** |
| B5: policy does not reduce inequality | `test_b5_policy...` | CAUGHT |
| S1 warming, S2 redistribution, S3 growth, S4 unemployment: each effect removed | their tests | CAUGHT (4 of 4) |
| bounds: one of the two inequality clips removed | `test_b2_extreme` | MISSED (the two clips are redundant by design: the target clip and the final clip) |
| bounds: both inequality clips removed | `test_b2_extreme` | CAUGHT |
| E1: the start is not a fixed point | `test_e1` | CAUGHT |

**What the misses mean (measured):**
1. **R2.** The R2 sign test checks the **end of the chain**. Zeroing the link inequality → tension or tension → well-being does not fail it, because the effect still arrives through other paths (inequality lowers well-being directly; well-being lowers the tension target). The test is a valid check of "automation raises inequality, tension and lowers well-being" and **not** of each link.
2. **B5 "lag".** Assertion (b) (the response exceeds 0.05 later than tension exceeds the threshold) holds **even with no delay**: the response only reaches 0.05 once tension is 0.025 above the threshold. Measured first-year gaps: real module (tau_P 10 years) 6.25 years; **no delay 1.5 years**; long delay (40 years) 13.5 years. So **assertion (b) does not test a delay.** The module does have a delay (the policy response stays up to 0.135 below its own instantaneous target in the test regime, against 0.011 with no delay); the pre-registered test just did not isolate it.
3. **Bounds.** The single clips are redundant by design; removing both is caught.

**What was done about it (post-hoc, labelled):** the pre-registered tests are **unchanged**. Two **post-hoc** tests were added in `tests/test_s7_social_posthoc.py`: `test_link_signs` (each link's sign at the equation level) and `test_policy_response_lags_its_own_target` (the response stays above 0.05 below its target at some time). They catch the three non-bounds misses (**3 of 3**; run with `audit/t0/s7_mutation_check.py`). The bar of 0.05 was chosen **after seeing** 0.135 and 0.011 and is a structural check, not a criterion about the world.
