## 1. Readings fixed before any result

**What is ported.** Eight Earth4All.jl sectors, in this order: output, inventory, finance, labour market, public, demand, energy, and "other" (see 5). Each is one module `f3/sectors/e4a_<sector>.py`. Equations are transcribed one by one from `src/<sector>/subsystems.jl` with the source line of each equation in the module header or beside the equation; parameters and initial values from `parameters.jl` and `initialisations.jl`. The package's `*_support` systems are test scaffolding and are not ported (CLAUDE.md).

**Scenarios.** Giant Leap = Too Little Too Late parameters plus the overrides in `src/earth4all/scenarios.jl` lines 38-76 (demand 39-45, energy 48-51, output 67-68, public 74). Climate, foodland and population overrides are irrelevant (replaced sectors).

**Reference data, exported by name** (`audit/t0/earth4all_m4_export.jl`, one run of the pinned package per scenario): (a) every variable of the eight sectors at the 0.5-year points 1980.0, 1980.5, ..., 2100.0 (241 points), file `tests/fixtures/e4a_reference_<scen>.csv`, columns `sector.VAR` (VAR is the package's symbol); (b) the recorded inputs of the sectors (every variable one sector reads that another sector computes, plus the replaced-sector signals of D-023: `POP`, `GDPP`, `EGDPP`, `A20PA`, `OW`, `CAC`, `COFO`, `IPP`) on the 1/16-year grid, file `tests/fixtures/e4a_signals_<scen>.csv`, linearly interpolated by `ReplaySector` as in S1 and W3; (c) a name map symbol to description; (d) Earth4All.jl's own error against Vensim for every variable of the eight sectors: true relative error |julia - vensim| / |vensim| (median, 95th percentile, maximum, year of maximum, number of points excluded), both scenarios, stored in `audit/data/e4a_vs_vensim_<scen>.csv` as names and figures only. Rule for (d), fixed now: points where |vensim| <= 1e-6 x max |vensim| of that series are excluded from the relative error and counted; the package's own metric |julia - vensim| / (|vensim| + 1) is not used for the figures (CLAUDE.md lesson).

**Error measure.** For port value `a` and reference value `b` at a 0.5-year point: relative error |a-b| / |b| when |b| > 1e-6 x max_t |b|; otherwise the point passes if |a-b| <= 1e-6 x max_t |b|. A variable whose reference is identically zero is excluded and listed. Tolerance +-2% (D-004) at every one of the 241 points (a superset of every reported year). The reference's own error against Vensim is reported beside every figure (D-018) with the sentence that Earth4All.jl follows Vensim closely for most variables but not all, and that no claim is made that the port reproduces Vensim.

**Step effect (A4.1 first part), measured before the 0.25-year result is read.** Three runs per sector alone: (S0) the port with Euler at 1/64 year (the reference's own scheme; this tests the equations, expected far below 2%); (S1) RK4 at 1/64 year (the step-free limit: the difference from S0 is the reference's own Euler error); (S2) RK4 at the loop step 0.25 year, each loop step a single RK4 step (the F3 default, as S1 and the World3 ports). Reported for each state and headline variable: maximum error and first year above 2%.

**Stated rule for a smaller internal step, drafted before running (as D-031 was).** If any state or headline variable of a sector alone exceeds 2% in S2 in either scenario, that sector is advanced with internal sub-steps inside the 0.25-year loop step; the sub-step is the largest of the ladder {0.125, 0.0625, 0.03125 (RK4), 1/64 (Euler)} for which every state and headline variable of that sector is within 2% in both scenarios; it is a selection, not a relaxation: the tolerance stays 2%, and a sector that cannot meet 2% at 1/64 Euler is reported as failed. The coupled economy (A4.5) is a group in the D-031 pattern: one `Sector` of the loop that advances its members with sub-steps of one value (the largest rung of the ladder at which A4.5 passes, same 2%), members coupled explicitly at the start of each sub-step as in D-031, and the loop-facing interface unchanged (D-003 and D-022 are not edited). The rung chosen for each sector and for the group and the reason are recorded; any change to D-003 or D-022 would be a new decision drafted as text.

**Switch times.** `t > 2022` (strict), `step(t, ., 2022)` (>=), `pulse(t, 2022, 1)`, `t > 1984` and the ramp ends are handled as in W3 (S1 rule): the integration is split at each threshold inside the horizon, and conditionals see a time just inside the segment. The three typo candidates of the plan (`22022 + IPP` in population, `2020 + IPP` in foodland and demand `IC2022`): only demand `IC2022` (`demand/subsystems.jl:159`, ramp end `2020 + IPP`) is in a reused sector; the port **copies it as in Earth4All.jl** (so that the reference is reproduced), flags it in the module and the report, and records that whether Vensim has it was not checked. Population's `22022` is not in a ported sector.

## 2. Acceptance tests and readings

- **A4.1** per sector (files `tests/test_e4a_<sector>.py`): (1) the state names are the reference states; (2) the initial state equals the reference at 1980 (1e-9 relative); (3) S0 within 2% (equation fidelity; the measured figure is expected far smaller and is reported); (4) S2 within 2% and the step effect S0/S1/S2 reported; a failure is recorded as a strict xfail with its size and first year, never adjusted; (5) the rule above applied if (4) fails; (6) the sector publishes its outputs by name with units; (7) the output of one loop step equals the output of the same step run through `Model` (interface).
- **A4.2** (`tests/test_e4a_switches.py`): the warming channels `OWECC`, `OWELC` (output) and `OWTFP` (public) are switchable (three parameters `SW_OWECC`, `SW_OWELC`, `SW_OWTFP`, default 1, multiplying the channel coefficient; the only structural addition to the transcribed equations). (a) With the three off, output and public still pass A4.1: Earth4All.jl has no switched-off reference run, so (a) is tested as: with the switches off the sector run with recorded inputs stays within 2% of the reference on the variables the channel does not touch, and the size of the channel effect on the touched variables is reported, not judged; (b) switches on with `OW` held at `OW2022` = 1.35 equal the switches-off run (relative difference <= 1e-9, both scenarios); (c) `EDROTA2022` is a documented parameter of public (module docstring and parameter table in the report), and setting it to 0 changes `DRTA` after 2022 by exactly the term it multiplies (test).
- **A4.3** (`tests/test_e4a_demand.py`, report): the demand component comparison with Vensim from `audit/data/e4a_vs_vensim_<scen>.csv`: per variable true relative error, median and 95th percentile, both scenarios, all demand variables listed by name; D-004 is not relaxed: variables above 2% (p95 or max) are listed as deviations; the test checks that every demand variable of the port has a compared figure or a recorded reason; it does not assert that Earth4All.jl is within 2% of Vensim (it is known not to be, D-018).
- **A4.4** (`tests/test_e4a_labour.py`): T2 on the port with recorded `A20PA`: `WF <= WAP` at every 0.5-year point, both scenarios; the maximum ratio is reported beside the reference's (0.8144 TLTL, 0.8248 GL); the excess of `WF` over `AVWO` is reported (reference: up to 0.59%). The effect of the S3 automation input is recorded as not testable before M6.
- **A4.5** (`tests/test_e4a_economy.py`): the eight sectors in one group with the replaced-sector signals recorded (`POP`, `GDPP`, `EGDPP`, `A20PA`, `OW`, `CAC`, `COFO`, `IPP` through `ReplaySector`); within 2% at every 0.5-year point in both scenarios of: GDP (inventory), GDP per person (the recorded `GDPP` is an input; the check is `GDP/POP` of the port against the reference `GDPP`), inequality index (`INEQ`, `INEQI`), public spending (`GS`, `PSP`), energy mix (`REP`, `FEP`, `NEP`, `EP` and the shares `REP/EP`, `FEP/EP`, `NEP/EP`). All states of the eight sectors are also reported. Tested at the loop step 0.25 first; the rule above applies if it fails.
- **A4.6** (report only): the deviations of Earth4All.jl from Vensim above 2% (inequality `INEQ`, `INEQI` in demand; the well-being index is in the replaced wellbeing sector and is cited from `audit/T0-FINDINGS.md`), with the sentence required by D-018.
- **Suite:** the existing suite stays green apart from documented strict xfails.

## 5. What "other" is for (hypothesis, to be confirmed by the port)
From `audit/data/earth4all_cross_sector_links.csv`: the only variable of "other" read elsewhere is `CTA` (cost of the turnarounds, `CFETA = COFO + CE`), read by public (`ECTAF2022 = max(0, CTA - CTA2022)`, which feeds `PLUA`, the TFP loss from unprofitable activity, and, through public, the extra taxes of demand). The rest (`FB15`, `PB15`, `LK`, `IEL`, `RGGDPP`, `PGDPP`) are performance indicators with no downstream use. So "other" is needed by the economy only for `CTA`; it is ported (7 equations) so that A4.5 has its public-sector input live, with `COFO` (replaced foodland) recorded.
