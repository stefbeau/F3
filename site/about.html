About F3

Public draft, published 2026-10-21. Conditional scenarios, not forecasts.Every curve in the Explorer is the output of a model run under stated assumptions. None is a prediction, none has a likelihood, and recorded test failures are listed on the Limitations page (plan test A2.7).

What F3 is

F3 (Foundation for Earth) is an open global model of how the AI race interacts with the planet's limits and society's stability. It puts planetary-limits models (World3, Earth4All) and an AI-transition model (GATE, by Epoch AI) into one set of feedback loops. It does not predict the future: it produces conditional scenarios, meaning if these assumptions hold, then these trajectories follow, to show which levers and feedback loops matter. The project is led by Stéphane Beau, who approves or rejects every decision in its register.

This Explorer is an early, partial version: three pieces with one link between them (climate damage to World3 industrial output, off by default), with several recorded test failures, shown with their labels. Its purpose at this stage is to make the state of the work visible, not to inform decisions about the world.
