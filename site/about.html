About F3

Conditional scenarios, not forecasts.Every curve in the Explorer is the output of a model run under stated assumptions. None is a prediction, none has a likelihood, and this page is a local draft that has not been approved for publication (plan test A2.7).

What F3 is

F3 (Foundation for Earth) is an open global model of how the AI race interacts with the planet's limits and society's stability. It puts planetary-limits models (World3, Earth4All) and an AI-transition model (GATE, by Epoch AI) into one set of feedback loops. It does not predict the future: it produces conditional scenarios, meaning if these assumptions hold, then these trajectories follow, to show which levers and feedback loops matter. The project is led by Stéphane Beau, who approves or rejects every decision in its register.

This Explorer is a first, partial version: three pieces that are not yet coupled, with several recorded test failures, shown with their labels. Its purpose at this stage is to make the state of the work visible, not to inform decisions about the world.
